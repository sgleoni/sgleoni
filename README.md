# Samuele Leoni

**Game Programmer — Unity & C#**

I focus on the code that makes a game work: player controllers, game state, AI opponents, and core gameplay systems. Every project below is a complete, playable build rather than a fragment or a template.

## What I do

- **Gameplay programming** in C# with Unity (2D and 3D)
- **Game logic and AI** for turn-based and classic games in C++
- Core systems: player controllers, physics-driven mechanics, UI and game-state management
